Snack → GitHub

Token do GitHub

Crie um token de acesso pessoal do GitHub com permissão de escrita nos repositórios onde você quer enviar os projetos do Snack:

  1. No GitHub, vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Crie um token novo. Se você só vai commitar em repositórios que já existem, pode selecionar só eles em Repository access. Se também quiser usar o botão Criar repositório novo dentro do popup, escolha All repositories — um repo que ainda não existe não pode ser selecionado individualmente.
  3. Em Permissions → Repository permissions, dê acesso de Read and write a Contents.
  4. Só para o botão de criar repositório: ainda em Repository permissions, dê acesso de Read and write a Administration também.
  5. Copie o token gerado e cole abaixo.

Fica salvo só neste navegador, em armazenamento local da extensão.
